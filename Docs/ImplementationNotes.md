# Implementation Notes

Status as of 2026-07-19: the MVP game loop from [GDD.md](GDD.md) §9.1 is **implemented and playtested** (autopilot smoke test scored 2 points, death + game-over + best-score persistence verified in play mode).

## What's where

| Piece | Path |
|---|---|
| Playable scene (only scene in Build Settings) | `Assets/Scenes/Game.unity` |
| Runtime scripts | `Assets/Game/Scripts/` |
| Scene builder (regenerates everything) | `Assets/Game/Editor/GameSetup.cs` → menu **Tools ▸ Flappy Bird ▸ Build Game Scene** |
| Tuning values (GDD §3.3) | `Assets/Game/GameConfig.asset` (ScriptableObject) |
| Classic sprites/audio | `Assets/Game/Sprites/`, `Assets/Game/Audio/` — **do not ship publicly**, see GDD §2 |
| Pipe pair prefab (pooled) | `Assets/Game/Prefabs/PipePair.prefab` |

## Script map

- `GameManager` — state machine (GetReady → Playing → GameOver), scoring, best score in `PlayerPrefs["HighScore"]`, restart via scene reload, focus-loss freeze (tap to resume).
- `Bird` — Rigidbody2D physics, velocity-replacing flap, cosmetic rotation, 3-frame flap animation, random color per run, ceiling clamp, death on pipe trigger / ground collision.
- `PipeSpawner` — pooled pipe pairs, distance-based spawning, aspect-aware spawn/despawn x.
- `ScrollingTiles` — generic looping tile row with aspect-aware recycle; used by the ground (4 tiles, full speed) and the parallax background (5 tiles, quarter speed).
- `FlapInput` — new Input System: Space/Enter/W/Up, left click, touch, gamepad south.
- `ScoreDisplay` — bitmap digit renderer (classic 0-9 sprites) used by HUD and results panel.
- `UIManager` — Get Ready / HUD / Game Over panels, white death flash.
- `AudioManager` — the five classic one-shots (wing, point, hit, die, swoosh) plus a looping background-music source (`Assets/Game/Audio/music.wav`, an original license-free chiptune loop generated by `scratchpad/make_music.py`; the classic game shipped no music).
- `AutoPilot` — dev-only playtest bot (never in the saved scene; add to the Bird at runtime to smoke-test).

## How to play

Open `Assets/Scenes/Game.unity`, press Play. Tap/click/Space to flap. Portrait (9:16) Game View recommended.

## Not yet implemented (GDD v1.0 polish)
